## 文档
首先，如果你是linux党，那我得教你个函数
  - **`linuxTerminalCheck()`**  
      这个函数用于检测你是不是在tty环境内，无论你要搞阻塞输入还是无阻塞输入，你都有必要用这个函数检测一下环境
      当它返回`True`时，这代表你确实在tty环境里，但如果它返回`False`，那说明你可能不在纯tty环境内，这可能会导致阻塞错乱
  
然后就是接下来的函数了
  - **`getTerminalSize()`**  
    这个函数会返回一个元组，它的第一个元素是屏幕的长度（以字符数计算），第二个元素是屏幕的宽度
  - **`initGame()`**  
    它负责初始化`_maxScreenWidth`和`_maxScreenHeight`，当然，我不建议你直接用这两个变量来做你的游戏，这属于是内部变量了
  - **`clear()`**  
    很简单，就是清屏，但好像又不太简单
    这里面有我自己发明的一个脏矩形渲染的新变种：脏矩形清空
    简单来说就是它会记录刚才有哪些行是脏行，并在被调用时把这些脏行清空掉
    这完全是我自己发明的算法了，庆祝！🎉
  - **`getch(nodelay=True)`**  
    最难实现的一个，因为它同时包含了Windows的输入，Linux的输入，且两个系统的输入都有分别的阻塞版和无阻塞版，通过`nodelay`这个参数来控制，默认是`True`
    如果你开了无阻塞输入，那么当你没有按任何按键时，他会返回`None`
    linux下只在纯tty内保证有效
    以及关于如何获取按下的功能键，你可以使用你所使用的系统对应的映射表  
    例如Windows是WINDOWSKEYMAP，Linux是LINUXKEYMAP，而MacOS就没有专门的适配了，以及我们目前并未攻克Windows的功能键获取🤔，所以这个功能暂时只支持Linux  
    你可以像这样使用它
    ```python
    ch = escurses.getch()
    if ch == escurses.LINUXKEYMAP['KEYUP']:  # KEYUP是上箭头，类似的还有KEYDOWN，F11等，都是全大写，没有下划线哦
      # 这里放你的代码
      pass
    ```
  - **`drawChar(x, y, char, color)`**  
    它会在指定的`x`和`y`画一个你传入的字符，然后就没了，就这么简单
    至于它的原理......好吧我可以讲讲
    其实我们还有一个内部变量`_screen`，这是一个数组，里面存的是各个位置对应的字符，当你调用这个函数时，它会把你传入的字符和你传入的坐标组合成一个元组丢进这个数组的对应位置里，但是屏幕左上角的坐标其实是(1,1)而不是(0,0)，这个需要注意
    我们贴心的帮你把`x`和`y`调换了一下，这是因为实际绘制时是`y`在前`x`在后，但我们不想让你受苦，所以在这个函数里就把`x`和`y`调换了
    以及就是当你往color传入相应的参数时可以改变字符的颜色，颜色常量已经内置在了库里，比如`COLORRED`这样，该参数的默认值是`COLORDEFAULT`
  - **`drawStr(x, y, string, color)`**
    内部会逐次调用`drawChar`，`x`和`y`是字符串的起始坐标，从左往右打印，参数都和`drawChar`差不多
  - **`refresh()`**
    调用这个函数会将`_screen`数组里的字符一一遍历出来画到屏幕上，但不是全部都画，因为这里实际用了脏矩形渲染来节省性能
  - **`cursorEcho(echo)`**  
    当你往`echo`里传入`False`，这会隐藏你的光标
    如果传入`True`，光标又会显示出来
    以及`echo`的默认值为`False`
  - **`exitGame()`**  
    用于退出游戏
  - **`frameStart()`**  
    如果你想控制帧率，可以试试这个，在每次主循环的开头调用它，切记一定要是最最最开头，前面不能有其他代码，然后配合`sleepForFrame()`使用，就可以控制帧率
  - **`sleepForFrame`**  
    它会通过稍微停顿来将帧率控制到你所传入的帧率，这对某些不想手动写大量计算的人来说是个很好的东西
  - **`theLifeAndEverythingAndUniverseUltimateAnswer()`**
    我承认它的函数名真的很长，这是个彩蛋函数，无论你怎么调用它都会返回42

这基本就是全部内容了，祝你们能做出好的游戏！
